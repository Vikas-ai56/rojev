The missing piece: background reasoning

Today Jev (S2) wakes only when someone speaks or something goes wrong. All planning is hidden inside XR-1. Helix and Hi Robot have an S2 that thinks all the time.

Every option that plans steps needs an action model that follows step sentences. Whether XR-1 does is untested.

C

RynnUnify: what to borrow

One 16B model from Alibaba DAMO (Oct 2026). It plans a task as subtasks, imagines how each subtask should end, then acts.

Camera + task→Plan subtasks→Imagine each outcome as a short video→Act→Scene matches the imagined outcome = step done

Reported: 51.5% on 20 selected composite RoboCasa tasks, 46.7% on 3 real-robot tasks. The tasks were hand-picked, so this is not directly comparable with XR-1's 32% on unseen composite tasks.

Idea to borrowWhat it means for usCost
Each step says what "done" looks likeWrite an end state per step ("kettle on the stove") and let the done model check it. Asking "is this step done?" in general is what MJev and OneJev failed atLow
Imagine before a risky stepPredict the outcome before a grasp or release; feeds the feasibility check and the gripper freezeMedium
Think hard only when unsureRun expensive checks on demand, the same idea as ask-when-unsureLow
Planner and checker share one understandingThe done check uses the planner's own step definitions, not a separate judgeLow

Not to copy: it is 16B and trained end to end, so it needs fine-tuning for each robot. Imagining video takes seconds, too slow for an S2 that thinks continuously. Whether its weights are released is not checked.

  1. One India GPU box. Simulator, XR-1 and OneJev on it, each model on its own GPU. The Mac only views. Network ~10 ms.
  2. Faster XR-1 server. Warm-up, compiled kernels, image prep on the GPU. ~150–200 ms (estimate).
  3. Faster Jev. Keep connections open, both questions in one request, a deadline per call.
  4. Fair scoring. Keep the paused simulator, but add each model's measured delay back into simulated time, so reaction time counts.

Expected after: stop takes effect in ~0.2 s, a new task in ~0.6 s (estimates).

F

What next, in order

  1. Honest testing. Model delays added back into lockstep; time logged per stage; "held until timeout" counts as a fail.
  2. Controller fixes. The owner decides "finished"; decisions expire by camera-frame age; S1 failures reach the owner; "stop" skips the model.
  3. Latency. India GPU box, faster XR-1 server, faster Jev.
  4. Done signal. RynnValue or Robometer on a GPU, threshold per task, wired to "complete".
  5. Prove Jev helps. Calibrate act-or-ask on ~400 labelled lines; compare with simpler alternatives over 10 seeds.
  6. Background reasoning. An S2 that checks progress every second and writes the next step, with Jev as the gate. Hardware after.
